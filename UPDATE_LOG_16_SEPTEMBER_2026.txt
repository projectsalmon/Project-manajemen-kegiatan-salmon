[1] KEAMANAN & PENGUATAN FIRESTORE RULES (DEFENSIVE HARDENING)
--------------------------------------------------------------------------------
- Memperketat `firestore.rules` untuk menutup celah Fatal Privilege Escalation:
  * Pengguna biasa dicegah mendaftarkan diri atau mengubah profil menjadi 
    'role: admin' atau 'userRole: STAF_KELURAHAN'. Hanya akun resmi Admin yang 
    berwenang mempromosikan peran.
- Proteksi Data Pribadi Warga (Anti-PII Leak):
  * Warga biasa hanya memiliki hak baca untuk dokumen profil miliknya sendiri.
  * Direktori seluruh warga hanya dapat diakses oleh Admin & Pengurus RW.
- Pengamanan Update Dokumen Kegiatan & Pengumuman:
  * Warga biasa dibatasi hanya bisa memperbarui data kehadiran RSVP, riwayat 
    bacaan, dan counter. Warga tidak dapat mengubah status 'approvalStatus', 
    judul, maupun jadwal kegiatan panitia lain.
- Validasi Keamanan via Google Cloud Shell & Rules Playground:
  * Pengujian simulasi injeksi payload hacker menghasilkan respon "Simulated write denied".
  * Pengujian HTTP REST API publik menghasilkan respon "403 PERMISSION_DENIED".
