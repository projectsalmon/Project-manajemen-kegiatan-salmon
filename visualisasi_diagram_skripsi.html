Deskripsi Skripsi: Sequence Diagram di atas mendokumentasikan pemisahan tanggung jawab pada arsitektur React Native Komuniva, memperlihatkan bagaimana interaksi penekanan tombol konfirmasi kehadiran pada view diteruskan melalui Context Provider ke service layer secara asinkron, disimpan secara atomik pada basis data Cloud Firestore, dan langsung disinkronkan ke widget layar utama Android.
